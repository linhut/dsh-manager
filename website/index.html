一键安装 DSH

自动检测系统环境，智能选择安装方式，支持多版本管理和切换，让 DSH 安装变得像喝水一样简单。

  • 自动检测 Node.js 环境
  • 支持镜像源选择
  • 版本切换与回滚
🛒

插件市场

自动扫描 GitHub 上带有 dsh-plugin 标签的开源项目，提供可视化的插件浏览和安装体验。

  • GitHub 插件发现
  • 一键安装卸载
  • 自动更新检测
🩺

系统诊断

全面的环境检查工具，一键诊断 DSH 安装状态、网络连接、配置完整性，快速定位问题。

  • 环境完整性检查
  • 网络连通性测试
  • 配置有效性验证
⚙️

配置管理

可视化查看和编辑 DSH 配置，管理 LLM 提供商、Agent Presets 等核心配置项。

  • YAML 配置编辑
  • LLM 提供商管理
  • 配置项快速查询
💻

交互式 TUI

美观的终端交互界面，无需记忆命令，通过菜单导航完成所有操作，新手也能轻松上手。

  • 彩色菜单导航
  • 实时状态显示
  • 操作引导提示
🔄

版本管理

管理多个 DSH 版本，支持版本切换、升级检测、版本回滚，确保始终使用最适合的版本。

  • 多版本并行管理
  • 一键升级检测
  • 版本历史记录
