# Using Superpowers

## 何时使用

在开始任何对话时使用——确立技能调用纪律。

## 核心规则

- **先技能后行动**：在执行任何代码探索、规划或编辑之前，检查请求是否匹配某个已安装技能的描述。若匹配，第一步行动是加载该技能并让其驱动——包括提出问题——而不是开始探索或写代码。
- 发布一行说明正在使用哪个技能；若跳过了明显匹配的技能，说明原因。
- 若有多个技能匹配，使用覆盖该请求的最小集合；若无匹配，正常进行。
- 设计/头脑风暴/规划类意图（"帮我想想""如何设计"）——技能优先，绝不跳过匹配技能直接写代码。

## 流程

1. 读取请求
2. 对照已安装技能列表（名称 + 描述）
3. 匹配 → `use_skill` 加载并遵循；不匹配 → 正常处理
4. 若技能驱动一轮提问式澄清，让其问题通过结构化提问界面呈现

## 注意

- 技能优先规则优先于默认的"先探索再行动"流程
- 加载技能后，澄清提问、探索、规划均由技能指导
