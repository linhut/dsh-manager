## 四、⚠️ 环境限制与落地说明（重要）

本仓库位于网络共享盘（`Y:\` = `\\192.168.1.115\迅雷\AI-DATA`）。实测发现该共享对**仓库中已存在的文件**拒绝所有写操作（覆盖 / 删除 / 重命名均被拒，报 Access denied / SAFE_DELETE_FAIL_CLOSED），仅允许**新建文件**。因此：

- ✅ 本次已落盘到项目（新文件）：补丁脚本、补丁文件、新增测试、本报告
- ⛔ 未能直接落地（修改已存在文件）：`config.js` / `app.js` / `model-config-center.js` / `capability-router/lib/index.js` 四个源文件的补丁

### 在可写环境落地的两种方式（任选其一，均需授权环境）

**方式 A：一键脚本（推荐）**
```bash
node scripts/_apply_patches.py        # 就地应用 8 个补丁（断言式，任一不匹配即中止）
node --test tests/*.test.mjs          # 回归（含新增测试，应 57 tests / 全绿）
```
> 注：脚本兼容 `--out-dir <dir>` 预览模式，可在应用前检查产物。

**方式 B：git apply**
```bash
git apply scripts/P0-P2-optimizations.patch
```
> `P0-P2-optimizations.patch` 为 unified diff（145 行，4 个文件）。

**方式 C：若本机为本地盘 checkout**：直接以 `C:\Users\Administrator\AppData\Local\Temp\dsh-patch\` 下的 4 个完整文件覆盖对应路径即可（该目录为标准项目相对结构）。

> 备份位置：`C:\Users\Administrator\AppData\Local\Temp\dsh-backup\`（含 4 个原文件）。
