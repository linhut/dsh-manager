# 信创环境部署指南

> 覆盖银河麒麟（Kylin）、统信 UOS、OpenEuler 等主流信创（国产化）操作系统。
> 按 CPU 架构分类，选择对应的安装包。

## 一、支持矩阵

| 信创环境 | CPU 架构 | 安装包 | 说明 |
|---------|---------|--------|------|
| 银河麒麟 V10（桌面/服务器） | x86_64（兆芯/海光/Intel/AMD） | `DSH-Manager-<版本>-amd64.deb` 或 `.AppImage` | 麒麟 x86 可用 |
| 银河麒麟 V10（ARM） | ARM64（飞腾/鲲鹏） | `DSH-Manager-<版本>-arm64.deb` 或 `.AppImage` | 麒麟 ARM 可用 |
| 统信 UOS（桌面/服务器） | x86_64 | `-amd64.deb` 或 `.AppImage` | UOS x86 可用 |
| 统信 UOS（ARM） | ARM64（飞腾/鲲鹏） | `-arm64.deb` 或 `.AppImage` | UOS ARM 可用 |
| OpenEuler / Anolis | x86_64 / ARM64 | `-amd64.deb` / `-arm64.deb` | 需手动安装依赖（见下） |
| 龙芯（LoongArch）/ 申威（SW64） | — | 无 Electron 安装包 | 用浏览器访问 DSH 网页（纯 Web 模式） |

> 从 GitHub Releases 下载：https://github.com/linhut/dsh-manager/releases
> 选择最新版本，按上表取对应架构的安装包。

## 二、安装

### 方式 A：deb 安装包（推荐，麒麟/UOS 原生格式）

```bash
sudo dpkg -i DSH-Manager-<版本>-amd64.deb
# 若提示缺少依赖：
sudo apt --fix-broken install -y
```

### 方式 B：AppImage（免安装）

```bash
chmod +x DSH-Manager-<版本>-x86_64.AppImage
./DSH-Manager-<版本>-x86_64.AppImage
```

> 若 AppImage 无法运行，先安装 FUSE：
> ```bash
> sudo apt install -y libfuse2   # Ubuntu/Debian 系
> sudo yum install -y fuse       # OpenEuler 系
> ```

## 三、DSH 环境准备

DSH Manager 需要管理 DSH（DeepSeek Harness）运行环境。信创系统上请确保：

1. **Node.js ≥ 20**（银河麒麟/UOS 自带版本可能较低，用 nvm 升级）：

   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
   source ~/.bashrc
   nvm install 20
   nvm use 20
   ```

2. **npm/pnpm 任一可用**（DSH 全局安装需要）：

   ```bash
   npm install -g npm@latest
   # 或
   npm install -g pnpm
   ```

3. **网络**：AI 功能需联网访问大模型 API（DeepSeek/通义千问等）；信创内网环境需配置代理或使用内网大模型网关。

## 四、龙芯 / 申威（纯 Web 模式）

> 龙芯（LoongArch）/ 申威（SW64）架构上 Electron 桌面应用不可用，DSH 本身是
> Node.js Web 服务，可用浏览器直接访问：

```bash
# 1. 安装 Node.js >= 20（龙芯 loongnix 自带，申威需编译安装）
# 2. 全局安装并启动 DSH
npm install -g @deepseek-ai/dsh
dsh web
# 3. 打开系统自带浏览器（Firefox / 360 安全浏览器）
#    访问 http://127.0.0.1:3080
```

> DSH Manager 的桌面管理能力（一键安装/配置/模型路由）在龙芯/申威上暂不可用，
> 请在其他 x86_64 / ARM64 机器上使用 Manager 完成配置后，将 `~/.dsh` 目录同步到信创机器。

## 五、常见问题

| 问题 | 处理 |
|------|------|
| deb 安装提示依赖缺失 | `sudo apt --fix-broken install -y` 后重装 |
| AppImage 双击无反应 | 终端运行看报错；确认已安装 libfuse2 |
| 打开后检测不到 DSH | 确认已全局安装 DSH；先在浏览器试访问 127.0.0.1:3080 |
| 端口被占用/页面白屏 | 在 Manager 点「🔄 重启 DSH」由 Manager 重新托管 |
| 内网无法访问外网 API | 配置系统代理，或在 DSH 设置中指向内网大模型网关 |
